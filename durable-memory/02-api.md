# API

Package io.lmctl.lmcode: Program.load, Registry.function/method/context, Context, Value, VmString and VmException. Schema hash binds exact bytes; callbacks bind canonical typed signatures. Registries default to 171 standard v2 signatures; Registry(false) opts out. SchemaSignatures normalizes declarations; PinVerifier checks exact canonical std/registry parity.

VmString is immutable bytes, including NUL and invalid UTF8. Only explicit text conversion uses Java Strings. Arithmetic wraps signed64-bit integers, float output follows15-significant-digit reference formatting. Ordered maps (`StrMap`, `IntMap`, `FloatMap`) preserve insertion order. Typed stacks/queues (`{Int,Float,Str}{Stack,Queue}`) iterate in pop order via `len`/`at`; priority queues (`{Int,Float,Str}PQ`) use a stable min-heap with insertion-sequence ties (signed zero priorities tie). `Json` (`json_parse`) parses strict UTF-8 JSON with depth <= 256, int64 integers, finite binary64 floats, raw token spelling preservation in `to_json`, borrowed child navigation, and arena-tracked `keys()`. `Stdlib.collectionValues`/`mapEntries` and `Stdlib.makeStrList`/`makeIntList`/`makeFloatList`/`makeStrMap` provide host collection snapshots and factories. Error codes and source locations mirror the reference.
