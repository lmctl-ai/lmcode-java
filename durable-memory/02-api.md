# API

Package io.lmctl.lmcode: Program.load, Registry.function/method/context, Context, Value, VmString and VmException. Schema hash binds exact bytes; callbacks bind canonical typed signatures. Registries default to 206 standard v3 signatures; Registry(false) opts out. SchemaSignatures normalizes declarations; PinVerifier checks exact canonical std/registry parity.

VmString is immutable bytes, including NUL and invalid UTF8. Only explicit text conversion uses Java Strings. `str_base64_encode`/`str_base64_decode` implement canonical padded RFC 4648 Base64 (rejecting whitespace, URL-safe alphabet, invalid padding, and nonzero pad bits); `str_hex_encode`/`str_hex_decode` implement lowercase hex encode and strict even-length mixed-case ASCII hex decode. Arithmetic wraps signed64-bit integers, float output follows15-significant-digit reference formatting. Ordered maps (`StrMap`, `IntMap`, `FloatMap`) preserve insertion order and expose `keys()`/`values()` returning independent arena-allocated list snapshots (`StrList`, `IntList`, `FloatList`). Typed stacks/queues (`{Int,Float,Str}{Stack,Queue}`) iterate in pop order via `len`/`at`; priority queues (`{Int,Float,Str}PQ`) use a stable min-heap with insertion-sequence ties (signed zero priorities tie). `Json` (`json_parse`) parses strict UTF-8 JSON with depth <= 256, int64 integers, finite binary64 floats, raw token spelling preservation in `to_json`, borrowed child navigation, and arena-tracked `keys()`. `Stdlib.collectionValues`/`mapEntries` and `Stdlib.makeStrList`/`makeIntList`/`makeFloatList`/`makeStrMap` provide host collection snapshots and factories. Error codes and source locations mirror the reference.

Registry.setResultSink binds an invocation-owned ResultSink, not an arena value. Reports.resultFrame / writeResultFrame are explicit success-only host helpers. See 09-invocation-results.md.
