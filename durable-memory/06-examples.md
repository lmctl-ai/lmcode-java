# Examples

Six independent .lms gallery programs: byte_strings, ordered_map, rounding_wrap, multilingual_greetings, file_pipeline, standard_catalog. Each computes data through lmcode-java, checks results, writes local data/ files and renders images/<name>.png with lmplot. Both subprocesses must exit0. examples/render-all.sh uses isolated directories and copies results to docs/images. Six900x560 PNGs, all under35KB; visual QA96/pass after correcting zero baselines and clipped impulses. README captions use full lmctl autorun raw URLs.
